# IoT Project (PlatformIO + Wokwi)

## 🚀 Overview
IoT development platform using C++ with PlatformIO and Wokwi simulator for rapid prototyping of embedded systems.

## 🛠 Tech Stack
- **Language**: C++ (Arduino)
- **Tools**: PlatformIO, Wokwi Simulator
- **Boards**: ESP32/Arduino Uno

## 📦 Project Structure
```
IoT_Project/
├── src/
├── include/
├── lib/
└── platformio.ini
```

## ▶️ Quick Start
1. **Wokwi**: Upload `main.cpp` to [wokwi.com](https://wokwi.com)
2. **Local**: 
```bash
pio run && pio run --target upload
```
